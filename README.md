# Tallinn Prayer Times

Phone-first PWA showing **next prayer** and **today’s times** for Tallinn, Estonia. Offline-capable via a service worker and a last-known-times cache.

**Live (GitHub Pages):** https://harkce.github.io/tallinn-prayer-times/

## Stack

Vite + React 18 + TypeScript + React Router + `vite-plugin-pwa`.

GitHub Pages serves the production build from the `docs/` folder on `main` (`base`: `/tallinn-prayer-times/`).

## Calculation source

Prayer times are computed with the same logic as [Eesti Islamikeskus](https://www.eestiislamikeskus.org/) (`app.js`), ported to `src/lib/prayer-calc.ts`:

- Tallinn coordinates `59.4370, 24.7536`, timezone `Europe/Tallinn`
- Fajr / Isha angle **15°**, Asr shadow factor **1**
- High-latitude Fajr night-portion guard
- **Isha month rules:** May–August → Maghrib + 90 minutes; other months prefer 15° with Maghrib+90 fallback when extreme
- Same rounding (Fajr round, Dhuhr/Asr/Maghrib/Isha ceil)

Do not replace `src/lib/prayer-calc.ts` with a third-party library if you want times to keep matching the mosque site.

## Local development

```bash
npm install
npm run dev
# open the URL Vite prints (usually http://localhost:5173/tallinn-prayer-times/)
```

Production build (writes to `docs/` for Pages):

```bash
npm run build
npm run preview
```

## PWA

- Web app manifest + icons under `public/icons/`
- Service worker generated by `vite-plugin-pwa` (precache + navigation fallback)
- Today also keeps the schedule in `localStorage` and shows an **offline** pill when the network is down

## GitHub Pages

Project site URL: `https://harkce.github.io/tallinn-prayer-times/

### Enable / update Pages

1. Repo **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder **`/docs`**

(An Actions-based Pages workflow was omitted because the push token may lack the `workflow` scope; branch deploy from `/docs` is enough.)

Enable via API (when allowed):

```bash
gh api -X PUT repos/harkce/tallinn-prayer-times/pages \
  -f build_type=legacy \
  -f source[branch]=main \
  -f source[path]=/docs
```

### Private repository note

Publishing GitHub Pages from a **private** repo requires **GitHub Pro** (or an org plan with Pages). On a free private repo, Pages may refuse to enable; the site is still fully buildable/servable locally or from any static host. Making the repo public also enables Pages on the free plan.
